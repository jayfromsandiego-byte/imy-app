## Decisions

- Architecture: one single-file artifact; each view (landing, signin, studio, tribute, dashboard, checkout) is a full HTML document stored base64 in the shell, mounted in a full-viewport iframe. Preserves each locked design exactly; shell owns hash routing (#/, #/signin, #/studio, #/site/slug, #/dashboard, #/checkout) plus a state store (account, memorials) persisted to localStorage with in-memory fallback.
- Tribute is data-driven already (vars TODAY, MEMS, CHIPS, PHOTOS, CH, TAPES, PEOPLE graph + ROOT). Build patches each `var X=[...]` to `(window.IMY_OVERRIDE||{}).X || [...]` so Eleanor stays the pristine fallback at #/site/eleanor; user pages inject override via srcdoc splice at `<!--IMY_OVERRIDE_SLOT-->`. Hydrator script (injected after main script) rewrites static texts (title, h1, dates, quote, pronoun labels, flyer, share URLs), applies plan gating (free: 12 photos / 10 wall memories per landing pricing; Plus removes Made-with-love credit), honest visit counts (no fake increment for user pages), and edit-mode overlays that postMessage {imy-edit, kind} on click (targets: cover fields, .memcard, .chc chapters, .ph photos, .tape, .tcard tree nodes, flyer).
- Studio: builder-ref letter shell + CSS kept; left mini-preview replaced with the real tribute iframe (mode=edit); step engine rewritten. Steps as of Aug 24: name, portrait, background, pronouns, dates (selects only), home, quote, first memory, chapters, photos, tapes, family (12 relations with via-selectors), service, address+plan. CUT: relation-to-you step, nickname, story block, what-they-loved, song, every sub-line, every whisper.
- Fonts: landing canon = Besley + Caveat + Work Sans, applied product-wide (desk included).
- Pricing: $197 lifetime only (monthly retired, founder decision Aug 2026). Free: one memorial per account, 12 photographs, 10 wall memories, fully random 10-letter slug. Plus: more memorials (20% off each next promised — FAMILY20 promo still to mint), chosen address, AI photo restoration on feature lists. Family faces on the tree never count toward the album cap, and that exemption is deliberately unadvertised.
- Real integrations on the live domain: Google sign-in via production Supabase (PKCE), Stripe via production /api/stripe/checkout (plus_once). Off-domain artifact copies simulate both.
